
# Chocolate Sales Analytics
See the full Dashboard here- [App Power BI link](https://app.powerbi.com/groups/me/reports/81c8fe54-adf9-4e00-b8f8-e7f981950049/60e6b3f43035841aa015?experience=power-bi)


Awesome Chocolates is a fictitious manufacturing company that produces organic wholesome chocolates. The management team needs a way to track KPIs (sales, cost, profit, low box shipment), compare regional performance, analyze product-level trends, and identify low box shipments.

The dashboard showcases the company's chocolate sales analytics. We calculated various measures to examine sales, boxes, cost, and profit. How the salespeople and products are performing. We took an in-depth look at low-box shipment, month-on-month (MoM), and Year-on-Year (YoY) change for key metrics like sales, and profit.
The underlying data model represents a star scheme where the fact table (shipment table) is connected to the dimension tables (product, people, location, calendar) via relationships, based on a common field or keys.
